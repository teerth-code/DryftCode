# DryftCode

> Your hackathon wins, verified and permanent.

DryftCode is a SaaS platform for verified hackathon credentialing and portfolio management, built specifically for college clubs and students across engineering institutions.

## The Problem

Every year, thousands of hackathons happen at the college level — organized through WhatsApp groups, Google Forms, and quickly-built websites. Students put in real effort, win, build something they're proud of — and then have nothing credible to show for it. No verified record. No proof. Just a screenshot.

Clubs face the same problem — rebuilding registration infrastructure from scratch for every single event, with no reusable system in place.

## The Solution

DryftCode gives college clubs a zero-barrier platform to host hackathons, and gives every participant a verified, permanent digital record of their participation, projects, and wins.

## Features

- Club registration and hackathon hosting with minimal setup
- Student profiles with verified participation history
- Timestamped project submissions with GitHub and demo links
- Cross-verification system between organizers and participants
- Achievement badges for verified wins
- Leaderboard and submission review dashboard
- Hackathon discovery for students across colleges
- Signal feed and notifications

## User Flows

**Student:** Discover → Register → Submit → Get Verified → Build Portfolio

**Organizer:** Create Hackathon → Manage Submissions → Review → Announce Winners
